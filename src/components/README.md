# Components

Shared, reusable UI components. No business logic here.

| Subfolder | Description |
|-----------|-------------|
| `ui/` | Primitive UI elements (Button, Card, Input, Badge, etc.) |
| `layout/` | App shell components (Sidebar, TopBar, MobileNav, AppLayout) |
| `common/` | Shared cross-feature components |
| `charts/` | Reusable chart wrappers |

Each component has one responsibility and is fully typed.
