# Hooks

Custom React hooks that encapsulate reusable stateful logic.

| Hook | Purpose |
|------|---------|
| `useLocalStorage` | Read/write localStorage with SSR safety |
| `useDebounce` | Debounce a rapidly-changing value (e.g. search input) |
| `useToast` | Toast notification state |
| `useMoodHistory` | Fetch mood history with loading/error state |
| `useProfile` | Fetch user profile with loading/error state |
