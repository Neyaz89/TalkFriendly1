# Features

Feature-first architecture. Each subfolder contains all components, hooks, and logic for one feature domain.

| Folder | Description |
|--------|-------------|
| `auth/` | Login, register, forgot password, OTP screens |
| `landing/` | Public landing page sections |
| `dashboard/` | Home dashboard widgets and layout |
| `moods/` | Daily check-in and mood analytics |
| `ai/` | AI Companion chat interface |
| `journal/` | Journal list, editor, and entry view |
| `listeners/` | Listener browse, profile, and booking flow |
| `communities/` | Community list and detail/discussion view |
| `circles/` | Listening circles |
| `events/` | Weekly events |
| `affirmations/` | Affirmation management |
| `profile/` | User profile and achievements |
| `settings/` | App settings |
