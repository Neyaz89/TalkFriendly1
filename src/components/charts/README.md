# Charts

Reusable chart wrapper components built on Recharts.

| Component | Purpose |
|-----------|---------|
| `MoodLineChart` | Area chart for mood/energy/stress trends |
| `WeeklyBarChart` | Bar chart for weekly comparisons |
| `MiniSparkline` | Tiny inline trend line for dashboard cards |

All charts are responsive (`ResponsiveContainer`) and use the design system color tokens from `constants/index.ts`.
