# Common Components

Shared UI components used across multiple features.

| Component | Purpose |
|-----------|---------|
| `EmptyState` | Friendly empty content message with optional CTA |
| `PageHeader` | Consistent page heading with back link and action slot |
| `LoadingSpinner` | Page-level and inline loading indicators |
| `ConfirmDialog` | Accessible confirmation modal for destructive actions |
| `MoodBadge` | Color-coded mood level badge |
| `StarRating` | Read-only or interactive star rating display |
| `SectionTitle` | Consistent section heading with subtitle and action |
| `NotificationBell` | Dropdown notification center |
| `PwaInstallBanner` | Native-style PWA install prompt |
